## What I learned

- Learned when to use `return None` versus `raise ValueError`.
- `None` is appropriate when missing data is an expected situation.
- Exceptions are better for invalid input or unexpected problems.
- Learned that specific exceptions are more useful than generic ones.
- Reviewed how `try`, `except`, and `raise` work together.
- Continued practicing helper functions and code readability.
- Reviewed the idea of pure vs impure functions.
- Pure functions are easier to test, reuse and reason about.
